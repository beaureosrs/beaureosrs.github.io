Clipper privacy policy

Last updated: 6 November 2026

Clipper is a personal tool run on the owner's own computer. It is used only by the owner of the Off Mic YouTube channel.

What data it accesses

With the owner's permission, Clipper uses Google's YouTube Data API with one permission: upload videos to the owner's YouTube channel. It also reads public information about Creative Commons videos on YouTube.

How the data is used and stored

The sign-in token is stored only on the owner's computer and is used only to upload clips. Clipper does not collect, store, sell or share any personal data, and does not access data belonging to anyone else.

Clipper's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Questions: contact the Off Mic channel through YouTube.
